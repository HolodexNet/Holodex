# Holodex v4 — orientation

- Stack: React 19, Vite 8, TS 6, react-router v8, TanStack Query 5, zustand, Tailwind v4, Base UI wrapped shadcn-style in `src/components/ui`, sonner toasts.
- `legacy/` is the archived Vue 2 app (reference only, not linted or scanned for i18n). The earlier React rewrite (v3) is on branch `next` under `packages/react`.
- Branches: v4 work happens on `v4`; PRs target `dev`.
- Routes all live in `src/main.tsx`. Unbuilt legacy paths go in `PENDING_ROUTES` (renders NotReadyPage). Heavy pages are `lazy` imports with a default export.
- Pages live in `src/pages`. Standalone pages wrap their content in `PageShell` (`components/layout/page-shell.tsx`, width variants).
- App chrome: `components/layout/` holds header, `app-sidebar.tsx` (nav lists, a "Show more" tools list), `user-menu.tsx` (avatar dropdown) and `bottom-nav.tsx` (phones).
- API: the `api` object in `src/lib/api.ts`. `request()` adds the JWT via `auth: true | "required"`, enforces a rate-limit budget, throws `ApiError` with `.status`, and returns non-JSON bodies as text. Backend contracts are in `dev-docs-handoff/*.md`.
- Queries: the shared `queryClient` and common hooks are in `src/lib/queries.ts`; channel hooks (`useChannel`) are in `src/lib/channel-queries.ts`. Search hooks use `useDebounced` and query key `["autocomplete", q]`.
- Stores: `useAuth` (`user`, `jwt`, `logout`), `useSettings` (`set(key, value)`), `useOrgStore`. Permissions are in `src/lib/permissions.ts`.
- i18n: get `t`/`tc`/`tl` from `useT()` (`@/lib/i18n`). English source is `src/locales/en/ui.yml`, in vue-i18n format (`{name}`/`{0}`, `a | b` plurals, lists via `tl`). Add new keys to `en` only; other locales fall back to English until Crowdin syncs. Search `ui.yml` for existing, already-translated keys before adding new ones.
- Translations that contain HTML are rendered with `RichText` (`components/about/shared.tsx`), which allows a safe subset only. Never use dangerouslySetInnerHTML.
- Icons are Phosphor components generated by iconx into `src/components/icons`. Import them from `@/components/icons`; add new ones with `npx iconx add <name>`.
- Common UI: Button (use `nativeButton={false} render={<Link/>}` for links), Callout, Card/`cardVariants`, Field*, Input, Textarea, SimpleSelect, Combobox, Dialog, DropdownMenu, Sidebar*, StateMessage, ChannelAvatar, and SuggestField (`components/video-edit`) for typeahead text.
- Styling: `cn` comes from the `cn` package and variants use `cva`. Prettier: no semicolons, double quotes, width 80, sorted Tailwind classes.
- Comments are short doc comments that explain why, not what.
- Testable logic goes in `src/lib` with no React or DOM. Those files import each other by relative path ending in `.ts` (no `@/` alias), because tests run `node --test tests/*.test.mjs` on the `.ts` source directly. Avoid writing tests that tautologically validate small and simple functions, rather, test should only be on complicated business logic.
- Checks: typecheck with `npx tsc -p tsconfig.app.json --noEmit` (plain `tsc --noEmit` checks nothing), lint with `npm run lint`, test with `npm test`.
