# Translation tooling

The app's translation runtime is `src/lib/i18n.ts`. React components subscribe
with `const { t, tc, tl } = useT()`; imperative code uses `getT()`.

`x18n.config.ts` configures this API explicitly using the general preset.
It scans the current `src` tree, excluding the runtime implementation and
generated icons. The archived `legacy` app is outside this project's scan.

Locale catalogs live in `src/locales/<locale>/ui.yml` and `seo.yml`, with English
as the source locale. The filenames select delivery bundles, not namespaces:
use `component.mainNav.home` and `music.title`, never `ui.component.mainNav.home`
or `seo.music.title`. Crowdin continues to manage both files independently.

- `npm run i18n:doctor` shows detected resources and scanners.
- `npm run i18n:check` reports catalog and usage problems.
- `npm run i18n:ui` opens the translation editor.

The local YAML adapter handles list-valued messages and empty `---` documents,
which x18n 0.1.x's built-in YAML format does not index. Lists are exposed as
indexed keys (for example `views.settings.gridSize.0`); `tl()` usage marks the
whole list as used. Item edits preserve the YAML sequence.

Both UI `{name}` / `{0}` and SEO `{{name}}` placeholders are checked. Plural
`n` and `count` are implicit. Parameter checking is omitted for factories and
`tc()` because x18n cannot express different signatures and automatically
supplied plural parameters on one factory.

Extraction in `.ts` modules uses `getT().t(...)` and imports `getT`. In `.tsx`,
the general preset generates `t(...)`: ensure the enclosing component calls
`useT()` and imports it so language changes trigger a render. Review the
extraction plan before applying it.

When adding keys, keep UI text in `ui.yml` and metadata in `seo.yml`. x18n 0.1.x
chooses a destination for missing keys by matching existing key prefixes,
falling back to the first resource. It does not preserve bundle membership for
missing translations in an empty SEO file; add those directly to `seo.yml`.

Translation checks currently report existing missing/unused messages and four
French placeholder mismatches. They are not a clean CI gate yet.
