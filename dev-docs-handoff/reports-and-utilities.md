# API Handoff: Reports, external notice, and diagnostics

## Business Context
Reports request moderator review, channel additions, or contact support. A successful report response acknowledges handling, not approval. External notice asks the catalog to discover/refresh a video. Diagnostics expose runtime snapshots and should not be treated as stable product DTOs.

## Endpoints
All v2 routes require the API access gate. JWT is optional only for the video report; channel/contact handlers do not register JWT parsing.

| Method/path | Request | Success | Errors/notes |
|---|---|---|---|
| POST `/v2/reports/video/:id` | Field array below; optional JWT | 200 status text | 400 missing Reason/Comments; video lookup can 404 |
| POST `/v2/reports/channel` | `{embeds:[{title?,fields:[...]}]}` | Upstream status, empty body | 400 recently requested channel or upstream failure |
| POST `/v2/reports/contact` | Field array | 200 status text | Upstream failure may 500 |
| POST `/v2/external/notice` | `{url:string}` | 200 JSON-looking string `{state:"success"}` | See response variants below |
| GET `/v2/multiview/record/:link` | Encoded layout/link | 201 status text | Mutates hit count; 400 if missing link |
| GET `/v2/debug/chat_status` | None | Runtime chat status object or null | Diagnostic shape not versioned |
| GET `/v2/debug/live_cache` | None | Runtime live cache | Diagnostic snapshot |
| GET `/clusterMetrics` | No API gate/JWT in code | Cluster Prometheus text | Operational endpoint; collection failure 503 `{"error":"Cluster metrics unavailable"}` |

Example video report:

```json
[{"name":"Reason","value":"Incorrect topic"},{"name":"Comments","value":"This stream is a concert."},{"name":"Original Topic","value":"minecraft"},{"name":"Suggested Topic","value":"singing"}]
```

Example channel request:

```json
{"embeds":[{"title":"Add a Vtuber","fields":[{"name":"Name","value":"Example talent"},{"name":"Channel","value":"https://www.youtube.com/channel/UC_example"}]}]}
```

## Data Models / DTOs and Validation
```typescript
interface ReportField { name: string; value: string; inline?: boolean }
interface ContactPayload extends Array<ReportField> {}
```
Video report searches the field names `Reason`, `Comments`, `Original Topic`, `Suggested Topic` exactly. Reason and Comments must be truthy. Comments of length ≤3 return 200 without dispatch. Channel reporting reads URL from `embeds[0].fields[1].value`; shape/order matters. Text containing `Add a Vtuber` or `add a clipping` affects moderator routing; this is not a typed request-kind field.

## Business Logic & Edge Cases
- Blocked report submitters can receive a normal-looking 200 with no dispatch. Video reports also swallow upstream dispatch failures and return 200. UI copy should say submitted, not guaranteed delivered/resolved.
- Channel requests are suppressed for three days after successful dispatch. Duplicate returns plain text `Channel already requested recently.` at 400. The handler references user roles but has no JWT middleware, so sending JWT alone does not grant a documented role bypass.
- Reports dispatch moderation messages, but these docs were generated by reading code; no reports were sent as validation.
- External notice returns JSON-looking **text**, not a consistent JSON response. Missing URL gives 400 state `expect body to be json conforming to {url: string}, found nothing`; unparseable URL gives 200 state `not a valid url - cannot find YT video ID`; initialization failure gives 406 state `sth wrong, channel may not be in holodex or YT id is invalid`; other failure gives 500 state `sth wrong, misc exception`.
- Existing noticed videos are marked for recrawl; success does not mean refreshed metadata is immediately available.
- Multiview record is a GET mutation. Call for actual visits, not hover or prefetch. Shared link representation is also used by layout images in [static-feeds.md](static-feeds.md).
- Cluster metrics bypass ordinary API middleware. Deployment ingress should decide exposure; frontend product flows do not need them. `/metrics` is not registered by this client's metrics configuration. Debug results can change as backend workers update and have no stable field-level schema here.

## Integration Notes
Preserve forms until success; distinguish duplicate channel request from validation failure. Contact/report dispatch may be duplicated by automatic retries, so do not retry blindly. Poll normal catalog routes after external notice with cache-aware delay. Avoid optimistic claims of completed moderation/crawl.

## Test Scenarios
1. Correct field-array report, missing fields, and short Comments acknowledgment.
2. Channel duplicate 400 versus upstream empty-body failure.
3. External URL parse failure at 200 versus successful queued refresh.
4. Multiview record fires once per intended visit and handles 201 text.
